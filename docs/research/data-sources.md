# Data-source scorecard (Phase 0, Task 2)

Scope: end-of-day Vietnam equity data (HOSE, HNX, UPCoM) for 5/10/20-session swing research, manual trading only. Budget assumption: zero `[Owner decision needed]` (Owner decision 2). Assessed 2026-10-27 by reading public pages only; nothing was installed, signed up for, or run.

Conventions: `unknown` = the source is silent or the page could not be read. Software licence and data terms are separate columns. Data terms are given as four independent permissions: public access / storage / automated access / redistribution-or-model-training. A source is `research-only` unless its terms verifiably allow storage and automated access (Owner decision 1). Vietnamese originals were read where available; quotes are paraphrased in English.

## Headline findings

1. **No source qualifies as primary production pipeline today.** No candidate has terms that were both read and shown to permit storage and automated access for the data the endpoint returns. `[Owner decision needed]` (see Recommendation).
2. **vnstock Gen 5 is a key-registered product distributed as pre-compiled packages.** The current generation (Generation 5) ships as pre-compiled packages from vnstocks.com, and the GitHub README describes the repository's source as the legacy 4.x codebase kept for historical reference, with a Rust core in a Python layer `[Fact S2]`. Whether the Gen 5 core is closed source is not stated on the pages read `[Unverified → P1 check: read vnstocks.com software licence section on source availability]`. Upstream endpoints below were therefore read from the legacy 4.x source and may not match Gen 5 `[Assumption]`.
3. **The vnstock licence does not cover the data.** It states it grants rights to the software only and that each source's own terms govern access, storage, display and redistribution `[Fact S4]`.
4. **PyPI marked vnstock 4.0.8 as quarantined** pending a security review (2026-09-24, per the PyPI page as fetched) `[Fact S1]`. Treat as a supply-chain warning; Phase 1 must not install it without a review.
5. The licence text on the vendor site is version `license-2026.11`, published 24/10/2026, effective 30/11/2026; the repo and PyPI cite `license-2026.09` `[Fact S4]` `[Fact S5]`. The terms in force will change inside the next month; re-check before any Phase 1 use.

## Recommendation

- **Primary pipeline source: none qualifies.** No candidate has terms that were read and verifiably permit both storage and automated access for the data returned, and none was verified to carry delisted tickers, a documented adjustment method, or point-in-time fundamentals. `[Owner decision needed]`
- **Interim research-only sources** (exploration, not a stored production dataset): vnstock Community with VCI and KBS endpoints; MSN for global context; DNSE (use restricted to own trading `[Fact S21]`). Their wrapper licence is separate from, and does not grant, any data right `[Fact S4]`.
- **Fallback candidates to verify first (free of charge, need an account):** SSI FastConnect Data, because it is an official, documented API with daily OHLC and index components `[Fact S19]`. Opening an SSI account or key is a sign-up and needs owner approval `[Owner decision needed]`.
- **Reference and validation sources:** HOSE, HNX and VSDC public pages for cross-checking prices, listings and corporate events, once their terms are read.
- **Paid, not recommended now:** EODHD (its terms permit storage for Non-Professional Users `[Fact S24]`, but they are silent on automated access, and Vietnam coverage, delisted history and price are unverified), ICE and FiinPro (quote only). Per Owner decision 2, a paid source is recommended only when it closes a named gap; none is yet shown to.
- **Decisions the owner must make:** (1) approve opening an SSI key and reading its terms; (2) accept or reject interim use of vnstock/VCI/KBS for local research only, with no stored dataset treated as production; (3) approve contacting HOSE, HNX or VSDC for terms and quotes. `[Owner decision needed]`
